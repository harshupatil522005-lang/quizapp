PYTHON LOOPS — INTERVIEW QUESTIONS AND CODING PRACTICE
======================================================

SECTION 1: IMPORTANT THEORY QUESTIONS
-------------------------------------

1. What is a loop in Python?
   Answer: A loop repeatedly executes a block of code.

2. What are the main types of loops in Python?
   Answer: for loops and while loops.

3. What is a for loop?
   Answer: A for loop iterates over items in a sequence or another iterable.

4. What is a while loop?
   Answer: A while loop repeats as long as its condition is True.

5. What is the difference between for and while loops?
   Answer: A for loop is commonly used to iterate over a sequence or range. A while loop is commonly used when repetition depends on a condition.

6. What is range() in Python?
   Answer: range() produces a sequence of integers, often used with for loops.

7. What does range(1, 6) produce?
   Answer: The integers 1, 2, 3, 4, and 5. The stop value is excluded.

8. What do the arguments in range(start, stop, step) mean?
   Answer: start is the starting value, stop is the excluded ending value, and step is the increment or decrement.

9. What does break do?
   Answer: It immediately exits the nearest enclosing loop.

10. What does continue do?
    Answer: It skips the rest of the current iteration and moves to the next iteration.

11. What does pass do?
    Answer: It does nothing and is used as a placeholder where a statement is syntactically required.

12. What is a nested loop?
    Answer: A loop inside another loop.

13. What is an infinite loop?
    Answer: A loop that does not terminate normally, often because its condition never becomes False.

14. Can a loop have an else clause?
    Answer: Yes. A loop's else clause runs when the loop finishes normally, but not when it is exited by break.

15. What is the difference between break and continue?
    Answer: break exits the loop; continue skips the current iteration.

16. Can a for loop iterate over a string?
    Answer: Yes. It iterates over the string's characters.

17. Can a for loop iterate over a list?
    Answer: Yes. It processes each item in the list.

18. How do you avoid an accidental infinite while loop?
    Answer: Ensure the loop condition can become False and update relevant variables when needed.

19. What is the time complexity of a loop that runs n times and performs constant-time work each time?
    Answer: O(n).

20. What is the typical time complexity of two nested loops, each running n times?
    Answer: O(n^2), assuming constant-time work inside the inner loop.

21. What is the difference between range(5) and range(1, 5)?
    Answer: range(5) produces 0, 1, 2, 3, 4. range(1, 5) produces 1, 2, 3, 4.

22. How can you loop through both an item's index and value?
    Answer: Use enumerate(), for example: for index, value in enumerate(items).

23. How can you loop through two sequences together?
    Answer: Use zip(), for example: for a, b in zip(list_a, list_b).

24. What is an off-by-one error?
    Answer: A boundary mistake that causes a loop to run one time too many or too few.

25. Why is indentation important in Python loops?
    Answer: Indentation defines which statements belong to the loop body.

SECTION 3: NUMBER-BASED CODING QUESTIONS
---------------------------------------

Q11. Reverse a positive integer.

n = 1234
reverse = 0

while n > 0:
    digit = n % 10
    reverse = reverse * 10 + digit
    n //= 10

print(reverse)


Q12. Check whether a number is a palindrome.

n = 121
original = n
reverse = 0

while n > 0:
    reverse = reverse * 10 + n % 10
    n //= 10

if original == reverse:
    print("Palindrome")
else:
    print("Not palindrome")


Q13. Check whether a number is prime.

n = 17
is_prime = n >= 2

for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        is_prime = False
        break

if is_prime:
    print("Prime")
else:
    print("Not prime")


Q14. Print all prime numbers from 1 to 50.

for n in range(2, 51):
    is_prime = True

    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            is_prime = False
            break

    if is_prime:
        print(n)


Q15. Print the Fibonacci sequence for 10 terms.

a, b = 0, 1

for i in range(10):
    print(a, end=" ")
    a, b = b, a + b


Q16. Check whether a number is an Armstrong number (example: 153).

n = 153
digits = str(n)
power = len(digits)
total = 0

for digit in digits:
    total += int(digit) ** power

if total == n:
    print("Armstrong number")
else:
    print("Not an Armstrong number")


Q17. Find the greatest common divisor (GCD) of two positive integers using a loop.

a = 48
b = 18

while b != 0:
    a, b = b, a % b

print(a)


Q18. Find the largest digit in a positive integer.

n = 58321
largest = 0

while n > 0:
    digit = n % 10
    if digit > largest:
        largest = digit
    n //= 10

print(largest)

even_count = 0

Q29. Find duplicate values in a list.

numbers = [1, 2, 3, 2, 4, 1, 5]
duplicates = []

for number in numbers:
    if numbers.count(number) > 1 and number not in duplicates:
        duplicates.append(number)

print(duplicates)


Q30. Count the frequency of each item in a list.

items = ["apple", "banana", "apple", "mango", "banana", "apple"]
frequency = {}

for item in items:
    if item in frequency:
        frequency[item] += 1
    else:
        frequency[item] = 1

print(frequency)


Q31. Find the second-largest distinct number in a list without sorting.

numbers = [10, 5, 20, 8, 20, 15]
largest = None
second_largest = None

for number in numbers:
    if largest is None or number > largest:
        if number != largest:
            second_largest = largest
        largest = number
    elif number != largest and (
        second_largest is None or number > second_largest
    ):
        second_largest = number

print(second_largest)

Q33. Find common elements between two lists without duplicates.
